🧮 Calculator – Simple & Lightweight Android Calculator

A simple, modern, and lightweight calculator application developed using Android Studio.

Calculator is designed to provide a smooth and easy calculation experience with a clean, user-friendly interface. It is suitable for everyday mathematical operations and quick calculations.

✨ Features

- Simple and clean user interface.
- Fast and lightweight performance.
- Easy-to-use design.
- Basic mathematical operations:
  - Addition (+)
  - Subtraction (−)
  - Multiplication (×)
  - Division (÷)
- Designed for Android devices.

🛠️ Development

- IDE: Android Studio
- Platform: Android
- Languages: Java / Kotlin
- Project Type: Native Android Application
